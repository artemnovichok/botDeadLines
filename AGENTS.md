# Работа с Deadline Assistant

Перед изменениями прочитайте [README_AI.md](README_AI.md). Это вводная для следующего
AI-агента: цель продукта, карта реализации, ограничения, запуск и проверка изменений.
Подробная инструкция владельцу установки находится в [README.md](README.md).

- Сверяйте документацию с текущим кодом и тестами; старые отчёты описывают прошлые проверки.
- Сохраняйте общий путь анализа через существующие сервисы для бота, CLI и расписания.
- Не добавляйте в Git секреты, рабочие БД, Telegram-сессии, содержимое чатов и `data/`.
- Не перезаписывайте заполненный `.env` и не меняйте ключ шифрования существующих сессий.
- Для проверок используйте временные БД и моки. Настоящие обращения к Telegram/LLM
  и отправка сводок — эксплуатационные действия, которые могут тратить деньги
  или отправлять сообщения; выполняйте их в рамках запроса пользователя.
- При изменении схемы добавляйте миграцию Alembic и обновляйте `SCHEMA_REVISION`.
- Обновляйте вводную и инструкции, если меняете архитектуру, запуск или ограничения.
